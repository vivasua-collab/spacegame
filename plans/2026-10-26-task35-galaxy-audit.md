## Открытые вопросы
- bulgeDensity: docs §1.3 «множитель плотности ядра относительно нормы» — точной формулы нет → Решение: доля ядра = 0.15 × (bulgeDensity / 1.5), т.е. 1.5 → документированные ~15%; семантика фиксируется комментарием в коде + отчётом (архитектурный вопрос для владельца).
- bulgeRadius: параметр есть в docs §5.1 (#9, 1.0–5.0 кпк, σ ядра), но отсутствовал в GalaxyGenConfig → Решение: добавлен в конфиг (default 3000 пк), поведение по docs §1.1 п.4.
- Рукава: docs §1.1 п.2-3 (лог. спираль угол→радиус, гаусс ⊥ рукаву σ=arm_width) vs код (радиус→угол, архимедова спираль, угловое смещение) — исторический аудит v3 (G-20) зафиксировал как осознанное отклонение → НЕ переписано, помечено архитектурным вопросом (замечание: «визуально аналогична» неточно — семейство спиралей другое; r = R·θ/(2πb) вместо a·e^(bθ)).
- Мосты связности: конфликт «связность vs жёсткая дистанция/степень» → Решение: мосты кратчайшие, exempt от maxJumpDistance всегда (иначе связность недостижима в разреженных конфигах: ореол за диском, малый maxDist), лимит степени соблюдается при наличии ёмкости, при исчерпании — наименее загруженная пара (минимальное нарушение). Задокументировано в коде + docs §4.2 (архитектурный вопрос подтверждения владельцем).
- sort(() => rng.nextFloat() - 0.5) в generate-resources.ts:156,183 — некорректное перемешивание (непоследовательный компаратор: для одной пары (a,b) результат может меняться между вызовами; порядок зависит от алгоритма sort движка → V8 браузер ≠ JSC bun → кросс-окруженческая невоспроизводимость; также смещённое распределение перестановок) → задокументировано в отчёте, НЕ исправляется (файл READ-ONLY, этап D). Больше таких sort() в src/galaxy и src/core НЕТ (grep: только эти 2).
- PRNG-фикс меняет ВЕЗДЕ вывод генерации (все seed) — это неустранимо при исправлении коллизий seed; снапшот обновлён по документированной политике ломки; чужие тесты контент-агностичны (проверено).
