## Решение по архитектуре миграции/согласованности (ключевое)

**Версионно-совместимая материализация с отложенной миграцией** (вариант
аудитора «версионная совместимая материализация»):

- Загрузка НЕ материализует тела (0 затрат времени/размера; ленивость R-29
  сохраняется). Загрузка: restore baked-model → `setCurrentLookups()` (Б1,
  защита от холодного старта/чужой модели) → перепись ожидающих миграцию тел
  (только журнал, O(bodies), без lookups) → zod.
- Материализация (`materializePlanetDeposits`, вызывается колонизацией) —
  ЕДИНСТВЕННАЯ точка входа залежей в игру: replay снимка текущим кодом +
  **пересчёт сводного пула из свежей физики** продолжением того же RNG-потока.
  Для тел dv≠3 дрейф поглощается: пул следует за физикой. Пул ↔ залежи
  согласованы ПО ПОСТРОЕНИЮ для всех версий.
- **Б3 устраняется структурно**: выбор уникального ресурса планеты переносится
  из `aggregateResourceDeposits` (не воспроизводился при материализации) В
  `assignResourceDeposits` (воспроизводится бит-в-бит). Фаза выбора — КОНЕЦ
  потока (после воды/богатых залежей) → следовая физика R-36 бит-в-бит
  сохраняется; выбранный элемент: следы его руды СТИРАЮТСЯ, ставится ОДНА
  усиленная залежь (qty 4–6, availability 0.03–0.10, depth 4–5) на один
  не-океанский гекс. Пул = агрегация физики (руды→элементы по yield) +
  гарантия всех элементов (запись с `hexCount=0` = «геологическая оценка,
  не разведано»).
- Полностью океанские миры: assign рано выходит → физики нет → пул без
  «повышенной концентрации» (выбора нет) → все записи `hexCount=0` — пул
  больше НЕ сообщает о залежах, которых нет в гексах.
- `DEPOSIT_RNG_VERSION` 2→**3** (физика выбора + новый источник RNG пула).
  Нележебная генерация (типы/орбиты/луны/звёзды) НЕ меняется: `derive()` не
  потребляет родительский поток (проверено), `derive('ultra')` удаляется
  без сдвига.

### Контракт пула (новый, docs/31 §8.2)

- Пул планеты = Σ(залежи руд × доля выхода элемента) + гарантия всех элементов
  таблицы (оценочные записи, `hexCount=0`).
- Выбранный уникальный ресурс: ровно одна залежь его руды, qty 4–6 ОРЕ
  (элемента — qty×доля выхода, напр. Ir-ore 7.5/10 → 3.0–4.5 Ir), hexCount=1,
  depth 4–5, availability 0.03–0.10; извлекается буровой (порог ≤ 8 < 10).
- Отображаемая концентрация ВСЕГДА равна доступной добыче (тест без пропусков).
