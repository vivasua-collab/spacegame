# Task 30 (R-30): снятие заглушек совместимости сейвов v1/v2

Дата: 2026-08-31. Владелец: «На текущем этапе совместимость сейвов не
требуется. Нечего захламлять код. Старые сейвы я потер, потому "заглушки"
от V1 и V2 нужно убрать.»

## 1. Исходное состояние (после R-29)

Пайплайн `deserializeGameState` нёс три слоя совместимости:

| Слой | Код | Назначение |
|---|---|---|
| fmt-детект | `game-store.ts`: `if (raw.fmt === 3) … else …` | маршрутизация по версии формата |
| v2-декодер | `src/lib/save-format-v2.ts`: `expandSaveV2` (живой путь загрузки старых сейвов), `compactSaveV2` (только для тест-фикстур), `isSaveFormatV2`, `SAVE_FORMAT_VERSION` | чтение/запись формата R-28 |
| миграция флагов | `save-format-v3.ts`: `migrateLegacyDepositFlags` (запечённые тела v1/v2 → `depositsMaterialized=true`) | защита от повторного replay на старых сейвах |

Проблема: сейвы v1/v2 физически не существуют (владелец стёр; таблица
`GameSave` пуста — проверено запросом), а код-заглушки остаются и
захламляют пайплайн загрузки + поддерживаются отдельным файлом и 11-ю
тестами кодека v2.

## 2. Решение

**v3 — единственный формат. Строгий контракт вместо молчаливой совместимости.**

1. **Удалить `src/lib/save-format-v2.ts` целиком.** Переиспользуемые хелперы
   (`round3`, `roundSig4`, `TIER_TO_IDX`, `TIER_FROM_IDX`) переносятся в
   `save-format-v3.ts` (без них кодек v3 не работает — это его собственная
   логика округления/тиров, исторически выросшая в файле v2).
2. **Удалить `migrateLegacyDepositFlags`** из v3 — миграция нужна только
   старым сейвам, которых больше нет.
3. **`deserializeGameState`**: единственный путь — `expandSaveV3(raw)`
   без fmt-детекта.
4. **`expandSaveV3` — строгий guard:** `fmt !== 3` → `throw Error('Неподдерживаемый
   формат сейва: fmt=… (ожидается 3). Форматы v1/v2 больше не поддерживаются
   — начните новую игру.')`. Альтернатива «вернуть raw как есть» отклонена:
   v2-кортежи дошли бы до миграторов планет и тихо породили бы битое
   состояние (залежи-кортежи вместо объектов, dm/ds не развёрнуты).
   `loadGame` уже обёрнут в try/catch → отказ = `console.error` + `false`.
5. **UI-отклик при отказе** (`page.tsx:handleLoad`): тост «Не удалось
   загрузить сейв… (v1/v2 не поддерживаются)» — раньше `false` от
   `loadGame` игнорировался, клик по Load «ничего не делал».
6. **INSTRUCTIONS.md:** fmt-раздел — только v3, отказ старых форматов.
