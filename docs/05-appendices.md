## 2. Приложение B: Что было исправлено/дополнено по сравнению с черновиком

### 2.1 Уточнения по сравнению с оригинальной игрой «Полдень XXI века»

1. **Уточнено количество элементов**: оригинал использовал 50 элементов (не 118), плюс 60 видов полезных ископаемых — это разные сущности. Элементы — чистые химические элементы, полезные ископаемые — природные смеси (руды, минералы). В SpaceGame: 60 элементов (57 базовых + 3 трансурановых Np/Pu/Am из Block 01 P7) (см. [32-mendeleev.md](./32-mendeleev.md)).

2. **Добавлены инопланетяне**: Триниты и Странники из оригинала — это не фракции, а элемент среды. Триниты — враги для охоты, Странники — источник артефактов.

3. **Уточнена система строительства**: здания запоминают последнее задание и повторяют его автоматически — важная QoL-механика оригинала.

4. **Добавлен абордаж**: в оригинале можно было брать корабли на абордаж — это сложнее, но выгоднее обычного уничтожения.

5. **Уточнены пути развития**: в оригинале нет выбора рас/классов — развитие определяется действиями игрока. Колонизатор/торговец/пират — это не классы, а стили игры.

6. **Добавлена домашняя планета**: защищена от нападений — важная механика для новичков.

7. **Уточнена экономика**: внутренняя валюта + торговля между игроками (в сингле — с AI) + торговые караваны (можно грабить).

8. **Упрощён первоначальный набор элементов**: начать с ключевых элементов, расширять постепенно (в MVP — 22, сейчас 57).

9. **Добавлены условия победы**: в оригинале цели не были формализованы (игра была бесконечной MMO). Для сингла нужны чёткие условия победы (научная, экономическая, военная, дипломатическая).

10. **Выбран рекомендуемый стек**: Вариант A (Next.js + PixiJS + Web Worker) как оптимальный для среды разработки и скорости итераций (см. [01-tech-stack.md](./01-tech-stack.md)).

### 2.2 Дополнения SpaceGame по сравнению с оригиналом

11. **Процедурная галактика** — 500-2000 систем, спиральная структура, seed-based (оригинал: статическая карта).

12. **Физически корректная генерация** — закон Стефана-Больцмана для звёзд, Kopparapu HZ для обитаемой зоны, гравитация через радиус×плотность.

13. **Химически обоснованная система руд** — BakedGalaxyModel с автогенерацией руд из химических характеров элементов (см. [33-chemistry.md](./33-chemistry.md)).

14. **Модульная архитектура** — TypedEventBus + ModuleRegistry + GameMediator (см. [architecture/modular-bus.md](./architecture/modular-bus.md)).

15. **Мелкие фракции** — система независимых колоний с упрощённой моделью расчётов (см. [71-minor-factions.md](./71-minor-factions.md), планируется).

16. **Научно-фантастические правила** — 3 обоснованных допущения (WARP, щиты, квантовая связь), остальное в рамках науки (см. [00-ARCHITECTURE.md](./00-ARCHITECTURE.md) §0).

17. **Ускорение времени** — x1/x5/x15/x50 + активная пауза (оригинал: реальное время без ускорения).

18. **Сохранение в любой момент** — SQLite/Prisma с таймаутом и toast-уведомлениями.

### 2.3 Принципы адаптации для синглплеера

| Механика оригинала | Проблема в сингле | Решение SpaceGame |
|---------------------|-------------------|-------------------|
| Тысячи живых игроков | Нет социума | Крупные AI-фракции (5 базовых, расширяемо) + мелкие фракции |
| Торговля между игроками | Нет рынка | AI-торговцы с динамическим спросом/предложением |
| Нападения на караваны игроков | Нет караванов | AI-торговые маршруты между системами |
| Глобальная конкурентная экономика | Нет конкуренции | AI-фракции конкурируют за ресурсы и системы |
| Ожидание реального времени | Скучно одному | Ускорение времени (x1/x5/x15/x50) + активная пауза |
| Союзники/враги — живые люди | Нет социума | Дипломатия с AI-фракциями |
