## Система нумерации

Номерные файлы имеют формат `XX-название.md`, где `XX` — группа (десятки):
- Группа позволяет создавать **промежуточные файлы** в подгруппах (11, 12, ..., 21, 22, ...)
- **0x** — Архитектура (общая + технические под-документы)
- **1x** — Галактика
- **2x** — Звёзды
- **3x** — Планеты и ресурсы (подгруппа ресурсов: 31-resources, 32-mendeleev, 33-chemistry, 34-ores)
- **4x** — Здания
- **5x** — Корабли
- **6x** — Исследования
- **7x** — AI и фракции (включая мелкие: 71-minor-factions)
- **8x** — Боевая система (80-combat — планируется)
- **9x** — Зарезервировано

## Правила использования

1. **Документация первична.** Номерные файлы (`XX-*.md`) — носители истины.
2. **Отметки времени** — каждый номерной файл содержит `Создан:` и `Изменён:` в шапке.
3. **Перед изменением спецификации** — обсудить с владельцем проекта.
4. **При добавлении новой системы** — создать spec в `docs/` с соответствующим номером перед реализацией.
5. **При изменении реализации** — обновить `STATUS.md`, не править spec.
6. **Исторические документы** (`audit-history.md`, `*-verification.md`, `*-audit.md`) не править — они фиксируют состояние на момент написания.
7. **Научные правила** (см. `00-ARCHITECTURE.md` §0.1) — неизменны без явного решения владельца.
8. **Геймплейные упрощения** (см. `00-ARCHITECTURE.md` §0.4) — абстракции для снижения сложности, могут добавляться по согласованию.

## Обновление этого индекса

При добавлении нового документа в `docs/`:
1. Добавить строку в соответствующую группу (0x, 1x, 2x, ...)
2. Указать оценку токенов (`wc -c < file.md | awk '{printf "%d", $1/3.5}'`)
3. Обновить итоговую сумму в шапке
4. При необходимости — добавить в «Рекомендации по чтению»
