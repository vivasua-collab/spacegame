## 2. Этап 1: Ядро симуляции

**Срок:** 3–4 недели
**Статус:** ✅ Complete

### Задачи
- Генерация тестовой галактики (10 систем × 3 планеты → параметризуемо до 2000)
- Базовая добыча: шахта → ресурсы
- Рецепты: крафт материалов и компонентов
- Простой цикл: строить шахту → получать ресурс → строить завод
- Тиковая система с паузой и ускорением (x1/x5/x15/x50)
- Сохранение/загрузка через SQLite/Prisma

### Ключевой результат
Рабочий UI-прототип: генерация галактики, застройка планет, добыча ресурсов, управление временем.

---

## 3. Этап 2: Базовый UI + Система ресурсов

**Срок:** 4–5 недель
**Статус:** 🔧 ~90% завершён

### Задачи
- Карта галактики (SVG/PixiJS, зум, панорамирование)
- Экран планеты (здания, ресурсы, очереди)
- Экран строительства
- Панель ресурсов (текущий баланс, доход/расход)
- Система сохранения/загрузки (SQLite, toast, оптимизация)
- 57 элементов с химическими характерами
- BakedGalaxyModel (автогенерация руд)
- Колонизация планет

### Ключевой результат
Играбельный интерфейс + химически корректная система ресурсов с автогенерацией руд.

---

## 4. Этап 2.5: Стабилизация и технический долг

**Срок:** ~1 неделя
**Статус:** ⏳ Pending

### Задачи
- Критические баги (P1: ID руд, P2: immutable store, P3: UI атмосферы/орбиты)
- Незавершённость (P4: UI очереди производства, P5: ResourcePanel, P6: Colony Hub, P7: transuranic)
- Тесты (PRNG, генерация, экономика, сериализация) — критично для ИИ-агентов
- Чистота кода (удалить deprecated, вынести хардкод, разбить крупные файлы)

### Ключевой результат
Стабильная, протестированная кодовая база, готовая к добавлению флота/исследований/AI.

> Подробности — в [`checkpoints/05_12_dev_plan.md`](../checkpoints/05_12_dev_plan.md) и [`STATUS.md`](./STATUS.md) §4-5.

## 5. Этап 3.0: Флот и исследования

**Срок:** 3–4 недели (после Etap 2.5)
**Статус:** ⏳ Pending
**Спецификации:** [50-ships.md](./50-ships.md), [60-research.md](./60-research.md)

### Задачи
- Корабли: конструктор (drag & drop модулей)
- Корабли: флот-менеджер (экран флота, приказы: move/patrol/colonize)
- Корабли: перемещение по Jump Points (WARP между системами, классическая механика внутри)
- Исследования: дерево (10-15 базовых технологий → 72 технологии)
- Исследования: интеграция (лаборатория, очередь, требования)
- Экран флота

### Ключевой результат
Игрок может строить корабли, формировать флоты, исследовать технологии.

---

## 6. Этап 3.5: AI-фракции

**Срок:** 3 недели (после Etap 3.0)
**Статус:** ⏳ Pending
**Спецификации:** [70-ai.md](./70-ai.md), [71-minor-factions.md](./71-minor-factions.md) (планируется)

### Задачи
- Крупные AI-фракции (2-4): экономика, флот, дипломатия, исследования
- Мелкие фракции / независимые колонии (упрощённая модель)
- Экономический AI (потребности, приоритеты строительства)
- Военный AI (формирование флотов, оценка угроз)
- Дипломатический AI (отношения, предложения)
- Торговля с AI (динамические цены, спрос/предложение)
- Экспансионистский AI (колонизация)

### Ключевой результат
Живая галактика с конкурирующими фракциями и торговыми отношениями.

---

## 7. Этап 4: Глубокие системы

**Срок:** 6–8 недель
**Статус:** ⏳ Pending

### Задачи
- Полное дерево технологий (72 технологии, 6 веток)
- Конструктор кораблей (все классы корпусов и модулей)
- Боевая система (см. [80-combat.md](./80-combat.md), планируется) — классическая механика в гравитационных колодцах
- Глобальная карта галактики с зумом (оптимизация LOD)
- Межпланетная логистика (торговые маршруты)
- Артефакты и руины (ксеноархеология)
- Дополнительные AI-фракции (до 5)
- Макрообъекты галактики (туманности, пустоты, реликты)

### Ключевой результат
Полноценная 4X-игра с исследованиями, боем, дипломатией.

---

## 8. Этап 5: Полировка и контент

**Срок:** 6+ недель
**Статус:** ⏳ Pending

### Задачи
- Полный набор рецептов (все элементы покрыты)
- 3–4 AI-фракции с разными стратегиями + множество мелких фракций
- Условия победы (научная, экономическая, военная, дипломатическая)
- Балансировка экономики и боя
- Триниты (агрессивные инопланетяне)
- Звуки и визуальные эффекты
- Обучение / туториал
- Оптимизация производительности

### Ключевой результат
Релиз-кандидат: играбельная от начала до конца игра.

## Монетизация (не для MVP)

Поскольку это однопользовательская игра — **монетизации нет**. Возможные модели:
- Бесплатная с открытым исходным кодом

- Steam-релиз за $10–20 (если мигрировать на Electron/Godot)
