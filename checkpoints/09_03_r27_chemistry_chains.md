## Выполненные задачи

### 1. Переименование/переопределение руд (данные)
- **Уголь** (`C-ore`, id сохранён): containedElements = C 8.0 (следы H/O/S убраны);
  рецепт `smelt_c` «Переработка угля» → `{ C: 8.0, slag: 2.0 }`.
- **Песок** (`Si-ore`): SiO₂, выход Si 4.7 / O 5.3 (без изменений химии);
  рецепт «Плавка кремния (песок)».
- **Каолин** (`Al-ore`): формула Al₂Si₂O₅(OH)₄ (Al₂Si₂O₉H₄), M = 258.2;
  выход по молярной массе: Al 2.1 / Si 2.2 / O 5.6 / H 0.2; рецепт «Обжиг каолина».
  Каолин дополнительно стал источником Si/O/H (реалистичная полиминеральная руда).
- **Шлак** (`slag`): новый ресурс в `CRAFTED_MATERIALS` (символ `Sl`, «crafted»),
  описание: побочный продукт, на следующем этапе — в бетон.

### 2. O/H = ВОДА (генераторы)
- `generate-resources.ts`: атмосферные элементы (H, He, N, O, Ne, Ar) **больше не
  создают залежей в породе** — раньше elementToOre маппил их на газы ('H2'/'O2'/…)
  и они попадали в гексы как «залежи газа». Исключены и из блока «богатых залежей».
- Вместо них — **Вода (H2O-ice)** как единственная залежь-источник H и O:
  `WATER_ABUNDANCE` по типам планет (ice 3.0 / oceanic 2.5 / rocky 0.4 /
  volcanic 0.2 / dwarf 0.3 / desert 0.15 / gas_giant 0).
- «O-rock» (кислородсодержащие породы) удалён полностью: ORE_SPECS,
  SPECIAL_ORE_SPECS (теперь пуст), ORE_DEFINITIONS, QUARRY_ORE_IDS, RAW_ORES,
  рецепт process_rock, CHEMICAL_DECOMP_IDS.
- Лёд переименован: «Водяной лёд» → **«Вода (лёд)»** (ice-generator + ICE_COMPOUNDS).
- Атмосферные газы (O₂/H₂ в standard/dense и т.д.) остаются добычей газового
  экстрактора из атмосферы — это не залежи; чистые газы конвертируются напрямую.

### 3. Рецепты

- − `process_rock` (вместе с O-rock).
- Всего рецептов: 75 (−1 +1). RAW_ORES: 54 руды (−O-rock).

### 4. Справка — новая вкладка «Переработка» (reference-dialog.tsx)

  встречаются в виде отдельных залежей — это же вода!»).
- Блок «Новые цепочки (R-27)»: Уголь→C+Шлак, Песок→Si, Каолин→Al, Вода→H+O.
- 5 таблиц цепочек: Шахта (22), Карьер (11), Глубинная добыча (18),
  Атмосфера (11), Вода и лёд (5). Выход из 10 ед. — **по рецептам** (игровая
  правда), fallback — containedElements; пометки «рецепт в планах» для льдов
  без рецепта. Разрешение имён: ELEMENT_MAP → CRAFTED_MATERIALS (Шлак = Sl).
