## 3. Ключевое архитектурное решение (Б1+Б2+Б3 вместе)

**Версионно-совместимая материализация с отложенной миграцией** (вариант,
предложенный аудитором в Б2) — вместо загрузочной материализации R-36:

- **Загрузка НЕ материализует тела.** Р-36 материализовала все тела с dv≠текущей
  ПРЯМО при загрузке — это (а) вызывало `getCurrentLookups()` ДО инициализации
  (краш холодного старта — дефект Б1) или с моделью предыдущей игры, (б) раздувало
  следующий сейв (все тела dm=true → залежи всех гексов пишутся ≈ МБ на галактику).
  Теперь `deserializeGameState`: expandSaveV3 → zod → **baked-model загружаемой
  галактики + `setCurrentLookups`** (Б1; zod ДО установки lookups — отклонённый
  сейв не затирает модель активной игры) → перепись ожидающих (журнал, O(тел),
  без lookups и мутаций).
- **Материализация — единственная точка входа залежей в игру** (колонизация,
  `materializePlanetDeposits`): replay снимка ТЕКУЩИМ кодом + **пересчёт свод-пула
  из свежей физики продолжением ТОГО ЖЕ RNG-потока** (та же функция в той же точке,
  что при генерации ⇒ пул при генерации и при replay бит-в-бит идентичен). Для тел
  dv≠3 дрейф поглощается: пул следует за физикой — несогласованность исключена
  ПО ПОСТРОЕНИЮ (Б2). Явный console.warn версионной материализации (без молчаливой
  порчи — требование R-35/R-37).
- **Б3 устранён структурно:** выбор уникального ресурса переехал из
  `aggregateResourceDeposits` (отдельный поток `derive('ultra')`, НЕ воспроизводился
  материализацией — пул обещал 4–6, физика давала следы 1–3) ВНУТРЬ
  `assignResourceDeposits` (фаза в КОНЦЕ потока). Выбранный элемент (1–2 из пула,
  не профильные, без повторов): следы его руды стёрты, вместо них ОДНА усиленная
  залежь (qty 4–6 ОРЕ, availability 0.03–0.10, depth 4–5) на одном не-океанском
  гексе. Свод-пул = чистая агрегация физики (руды→элементы по долям выхода) +
  гарантия всех элементов (записи hexCount=0 = «геол. оценка», UI-метка).
  Поскольку фаза — в конце потока, следовая физика R-36 бит-в-бит сохранена;
  `derive()` не потребляет родительский поток (проверено) — нележебная генерация
  (типы/орбиты/луны/звёзды) не сдвинулась.
- **Полностью океанские миры** (Б3): assign рано выходит → физики нет → выбора
  НЕТ → пул целиком из оценочных записей hexCount=0. Пул не обещает физику,
  которой нет.
- **dv 2→3** (физика выбора + новый источник RNG пула). `dv` пишется только если
  версия известна — старые сейвы без `dv` проходят рантрип побайтно (прежде decode
  инъектировал версию 1 → encode писал «dv»:1 — рост сейва без пользы; найдено и
  исправлено в этом проходе).
- `migrateDepositsIfNeeded` удалена (единственный потребитель был в load-пути);
  `ds` у материализованных тел СОЗНАТЕЛЬНО не обнуляется (поведение R-29: защита
  контракта восстановления D2-теста 11; вес ~20 байт/тело).
