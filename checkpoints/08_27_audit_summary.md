## 2. Ревью кода — ключевые выводы

### 2.1 Архитектура ✅
- Реализована модульная шина: `TypedEventBus` (приоритеты, replay, defer/flush), `ModuleRegistry` (топосорт зависимостей), `GameMediator` (центральный оркестратор).
- Каталог 60+ типизированных событий (`src/core/events.ts`).
- Контракт `IGameModule` с lifecycle, два модуля-гражданина: `EconomyModule`, `GalaxyModule`.
- Legacy `event-bus.ts` сохранён как адаптер (обратная совместимость).
- Документ: `docs/architecture/modular-bus.md` (~2050 строк).

### 2.2 Ядро симуляции ✅
- PRNG xoshiro256** с 4-мя независимыми хешами `derive()` (детерминизм верифицирован, 6/6 PASS).
- `GameLoop` — пауза, x1/x5/x15/x50, отдача приказов во время паузы.
- Сохранение/загрузка через SQLite/Prisma (`/api/save` GET/POST/PUT/DELETE), таймаут 30 с + `AbortController`, toast-уведомления.

### 2.3 Галактика ✅
- Спиральная генерация (ядро/диск/ореол), 500 систем (параметризуемо до 2000).
- 12 типов звёзд, двойные/тройные системы, температура по Стефану–Больцману.
- 7 типов планет, гекс-сетка (19/37/61/91/127), 8 типов атмосферы, 5 уровней жизни.
- Газовые гиганты: 0 гексов + `atmosphericSlots` + `orbitSlots`.
- Jump Points + связность через BFS.
- Гравитация: нормализованная поверхностная формула `g/g_E = (ρ/ρ_E)(R/R_E)` — **физически корректна** (линейная по R при постоянной плотности; вывод через `g = GM/R² = (4/3)πGρR`).

### 2.4 Ресурсы и химия ✅
- **57 элементов** (см. `src/data/elements.ts`, `docs/32-mendeleev.md`) с `chemicalCharacter`, `oxidationState`, `rarity`.
- ~50 руд автогенерация через `BakedGalaxyModel` (`chemistry-generator.ts`, 1704 строки).
- Lookup-структуры в `baked-lookups.ts` (синглтон).
- Атмосферные соединения (11 газов), ледяные (5 льдов), самородные (6).

### 2.5 Экономика 🟡
- `engine.ts`: добыча → крафт → энергия.
- Энергия — потоковый ресурс (не занимает склад).
- 12/27 зданий спецификации реализованы.
- 3 критических расхождения (P1, P3) + 4 средних (P4–P7).

### 2.6 UI 🟡
- Карта галактики (SVG, зум 80x), экран системы, экран планеты (гекс-сетка), панель ресурсов, управление временем.
- `building-dialog.tsx` поддерживает только surface-слой (нет UI для атмосферы/орбиты).
- Нет UI очереди производства (`enqueueProduction` есть, кнопок нет).

### 2.7 Качество кода 🟡
- Lint: 0 ошибок ✅.
- Тесты: 0 ❌ (критично для ИИ-агентов).
- Прямые мутации в `game-store.ts` (поверхностный клон → риск stale-ссылок).
- Дублирование `recalcEnergyBalance` (3 цикла), хардкод `ATMOSPHERE_GAS_MAP`/`DIRECT_GAS_MAP` в логике.
- `@deprecated event-bus.ts` и `extractOreToElements` — мёртвый код.
- `chemistry-generator.ts` (1704 строки), `planet-view.tsx` (846), `recipes.ts` (771) — крупные файлы требуют разбиения.

## 5. Противоречия внутри документации (5 пунктов)

Подробное исправление — в [08_27_doc_fixes.md](./08_27_doc_fixes.md). Кратко:

1. **AI-фракции** — `70-ai.md` говорит 5, `00-ARCHITECTURE.md` говорит 2–4. Решение: **5 базовых, расширяемо**.
2. **Количество элементов** — разные документы называют 50/57/22/118. Решение: **максимум = 57** (подтверждено кодом + `32-mendeleev.md`).
3. **Формула гравитации** — `30-planets.md` содержит корректную нормализованную формулу; необходимо привести все документы к единому физически достоверному виду.
4. **Универсальные vs специализированные переработчики** — `40-buildings.md` v2.0 убрал специализированные. Решение: **2 типа** (универсальный = мульти-ресурс с низким коэф.; специализированный = апгрейд универсального под конкретную цепочку с высоким коэф.).
5. **Пути** — исправить относительные пути/ссылки между документами.
