## 3. Решения (свёртка, с обоснованием)

1. **`aiFactions` опционален** — сохраняет tsc-базу Δ0 и побайтные якоря сериализации.
2. **Секция пишется только при непустом реестре** — старый v3-сейв проходит
   deserialize→serialize **без инъекции ключей** (аналог контракта dv/sv R-37/R-38
   «пишется только если известна»); пустой реестр эквивалентен отсутствию.
3. **Версия секции — плоский маркер `aiFactionsV`** (не вложенный объект): следует
   прецеденту dv/sv; при наличии реестра обязательна, иначе явный отказ загрузки.
4. **RETREAT_THRESHOLD НЕ в персистентном состоянии**: значение SWARM = Infinity не
   JSON-сериализуемо (`JSON.stringify(Infinity)` → `null` — тихая порча); представление
   («никогда») выберет военный срез 3б.4.
5. **Бюджетные веса — документированные плейсхолдеры**: в docs/70 констант бюджета нет
   (Приложение A задаёт только форму `budget_allocation`); значения профильные §2.1,
   сумма = 1; в 3б.1 НИКЕМ не читаются (нет потребителя) — баланс решит владелец при 3б.3.
6. **newGame НЕ создаёт фракции автоматически** (запрет «изменение поведения существующих
   систем» + целостность якорей sha256); setup — явный API (`setupAIFactions`), подключение
   к newGame — отдельное решение владельца.
7. **Контроллеры — кэш от реестра** (аудит R-43: постоянное состояние НЕ живёт в модуле,
   иначе терялось бы при load): sync в тике, сортированные ключи, идемпотентно; после
   game-loaded кэш сбрасывается и восстанавливается от ЗАГРУЖЕННОГО реестра (тест).

## 4. Контракты для следующих срезов

- Чтение реестра: `state.aiFactions ?? {}` (отсутствие = пустой реестр) — обязательная
  дисциплина для всех читателей.

## 6. Тесты (+36, tests/ai/factions.test.ts; написаны ДО реализации — TDD)

- Валидация (п.1 тест-плана): archetype/конфиг/бюджет (сумма≠1, отрицательные)/пороги/цели
  (дубликаты id)/createdAtTick; ключ реестра == id; константы архетипов == Приложение C.
- Roster (п.1/п.4): same seed → бит-в-бит идентичен; разный seed → разный; ids уникальны,
  ключи отсортированы, форма `ai_faction_NN`; count≤5 — архетипы без повторов; count>5 — цикл;
  createdAtTick прокидывается; невалидные опции — throw; конфиг согласован с таблицей §7.6.
- withAIFactions: устанавливает в НОВОЕ состояние (вход не мутируется); дубликат-регистрация —
  явный отказ; пустой существующий реестр не мешает; невалидный roster — отказ.
- Referential integrity (п.2): все owner-поля разрешаются; чужой owner — нарушение с путём;
  сущность фракции НЕ содержит копий (owned_systems/resources/fleets/researched_techs отсутствуют).
- Save/load v3 (п.5): старый сейв — рантрип БЕЗ инъекции AI-ключей; пустой реестр не пишется;
  сейв с фракциями — маркер aiFactionsV + save→load→save→load побайтно ×2; битая AI-секция ×3
  (версия≠1 / лишнее поле strict / бюджет) — явный отказ загрузки.
- Store action: регистрация по seed (воспроизводима); дубликат — false; без игры — false.
- Модуль: контроллеры от реестра (sorted, конфиг из фракции, perception строится); инертность
  ПРИ непустом реестре (тики с AI и без — GameState бит-в-бит идентичен); 3а-совместимость
  (ручные контроллеры без реестра сохраняются); lifecycle — повторный setLoadedState:
  подписки не растут, кэш сбрасывается, контроллеры восстанавливаются от загруженного реестра.
- Детерминизм (п.4): ×3 сборки in-process — sha256(GameState) и sha256(реестра) идентичны.
- Адаптация 3а-теста (tests/ai/ai-module.test.ts): assert версии манифеста 0.1.0 → **0.2.0**
  (манифест бампнут по конвенции; смысл теста «serialize возвращает версию манифеста» не ослаблен).
