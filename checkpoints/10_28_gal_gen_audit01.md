## 2. Точная текущая модель (как в коде, без интерпретаций)

```
T_пов°C = T_eq + ΔT_парник + ΔT_тип − 273.15

T_eq      = 278.5 · L^0.25 · (1−A)^0.25 · r^−0.5      [K]
ΔT_парник = base(тип_атмосферы) · (P/1 атм)^0.25       [K]
ΔT_тип    = volcanic +30…100 / ice −20…−50 / gas_giant +10…30 / desert −5…+10 / прочие 0 [K]
A (альбедо) = base(тип_планеты) + надбавка за co2/dense (+0.20…0.40, кап 0.80) или methane (+0.10…0.25, кап 0.60), общий кап 0.85
```

base парника: none 0 · thin 5–20 · standard 25–40 · dense 50–130 · co2 80–280 · methane 30–90 · toxic 10–35 · inert 5–15.

## 4. Сравнение с научным бейзлайном

### 4.1 Равновесная температура — СООТВЕТСТВУЕТ стандарту
Формула `278.5·L^¼·(1−A)^¼·r^−½` — в точности канонический вид
T_eq = (L(1−A)/(16πσa²))^¼ в солнечных единицах (константа 278.5 K =
(S₀/4σ)^¼ = 278.3 K — расхождение 0.2 K, допустимо).
Проверка «Земля» из docs §2.3 воспроизводится (тест T10): L=1, r=1,
A=0.30 → T_eq 254.8 K; +33 K → 287.8 K (14.6 °C) ✓.
Источники: Pierrehumbert 2010, Principles of Planetary Climate (Cambridge
Univ. Press), §3 «Radiative transfer»; NASA — science.nasa.gov/exoplanets/habitable-zone/;
Kopparapu et al. 2013, Astrophysical Journal 765:131, doi:10.1088/0004-637X/765/2/131.

### 4.2 Парниковая добавка — ОСОЗНАННОЕ УПРОЩЕНИЕ (не полная климатическая модель)
Модель `T = T_eq + ΔT(P)` — не радиационно-конвективная модель. Ограничения:
- **Линейная аддитивность** занижает горячие случаи: Венера (T_eq 227 K,
  поверхность 737 K) требует ~+510 K; класс co2 даёт максимум +280 K.
  Забеговый парник (runaway greenhouse) не моделируется — предел
  Симпсона–Накадзимы ~1.1 S₀ упомянут в docs/planet-generation-science.md,
  но в формуле не участвует.
- **Масштаб (P)^0.25** — грубая аппроксимация серой атмосферы; в
  optically-thick режиме исходящий поток ~ (D·P/g)^¼ для излучающего
  уровня — форма похожа, коэффициенты игровыe.
- Земное +33 K при standard 25–40 K — согласовано [Catling & Kasting 2017,
  гл. 4; en.wikipedia.org/wiki/Greenhouse_effect].
Вывод: для игры — разумный уровень 1 («равновесие + линейный парник»);
не заявлять как климатическую симуляцию.

### 4.3 Размер — корректно ОТСУТСТВУЕТ в T_eq
Физика: T_eq не зависит от радиуса тела (поглощение и излучение ∝ R²).
Размер реален через: (а) удержание атмосферы (escape velocity) — сейчас
не моделируется (atmosphereChance по типу, не по размеру); (б) внутренний
теплопоток — частично покрыт ΔT_type (gas_giant +10–30 K при фактическом
Jupiter-эффекте ×1.7 ≈ +50 K на уровне облаков); (в) тепловую инерцию —
не важно для генерации.
**Рекомендация: НЕ добавлять размер в формулу T_eq** — это было бы
научной ошибкой. Если владелец хочет влияния размера — легитимный путь:
вероятность удержания атмосферы от гравитации/размера (отдельное решение
по модели атмосферы, тогда T изменится КОСВЕННО и физично).
